# 대회 규정 준수 소명서

제3회 풍력발전량 예측 AI 경진대회(BARAM 2026) 규칙 3~6항에 대한 준수 근거를
코드 위치와 함께 정리한다. 2차 평가 코드 검증 시 이 문서를 기준으로 확인 가능하다.

## 3. Data Leakage 방지 규칙

### 기본 원칙 — 예측기준시점 이전 정보만 사용

각 예측값의 예측기준시점은 예보 발표 시각인 **전일 13:00 KST**이다.
사용하는 모든 정보가 그 시점 이전에 확정된 것임을 아래와 같이 보장한다.

| 사용 데이터 | 확정 시각 | 근거 |
|---|---|---|
| LDAPS / GFS 예보 | 전일 13:00 KST | 주최측 제공 원본의 `data_available_kst_dtm` 컬럼 |
| SCADA 실측 (학습 기간) | 2022-01-01 ~ 2024-12-31 | 평가 대상(2025년) 전체보다 과거 |
| 학습 라벨(KPX 발전량) | 2022-01-01 ~ 2024-12-31 | 동상 |
| 시간 파생(시각·요일·선행시간) | 달력 정보 | 관측 아님 |

### 예보 데이터 사용 기준

주최측 제공 파일은 이미 **매일 09:00 KST 초기화 예보 중 13:00부터 사용 가능한
익일 01:00~익익일 00:00 구간만** 추출해 제공된다. 따라서 원본 행을 그대로 쓰는 한
"예측기준시점 이후에 생성·공개된 예보자료"가 섞일 여지가 구조적으로 없다.

**시간 축 파생 변수의 누수 차단**: 시계열 컨텍스트 피처(lag/lead/rolling)는
`data_available_kst_dtm`이 동일한 24시간 블록 **내부에서만** 계산한다
([src/features.py](../src/features.py) `add_context`). 블록 경계는 NaN으로 두어
다음 발표분(미래에 공개될 예보)의 값이 유입되지 않는다.

전 변수·전 격자 피처([src/features_full.py](../src/features_full.py))는 동일
`forecast_kst_dtm` 행 안에서 격자·변수 간 결합만 수행하며 시간 축을 넘지 않는다.

### 실측 데이터 사용 기준

SCADA 실측은 **학습 기간(2022~2024)에만 제공**되며, 본 파이프라인도 그 기간에만
사용한다. 용도는 세 가지이고 모두 "모델 파라미터를 학습 데이터로 추정"하는 것과
동일한 지위이다.

1. **라벨 정제** ([src/scada.py](../src/scada.py) `build_mismatch_mask`)
   — 라벨과 SCADA 합계가 5%cap 넘게 어긋나는 학습 시간대를 학습에서 제외.
2. **가용률 보정 학습 타깃(potential)** (`build_potential`)
   — 터빈 정지 시간대의 학습 타깃을 정상 터빈 기준으로 복원. **검증·채점은 항상
   실제 KPX 라벨 기준**이며 potential은 학습 타깃으로만 쓴다.
3. **지형 보정표·경험적 파워커브** ([src/terrain.py](../src/terrain.py))
   — 풍향 섹터별 승법 보정계수와 풍속-출력 곡선을 적합. `fit_years` 인자로
   적합 연도를 명시적으로 강제하며, 각 검증 폴드는 **자기 학습 연도만**,
   최종 모델은 2022~2024만 사용한다.

2025년 실측값·사후 보정자료·재분석자료는 일절 사용하지 않는다.

### 금지 정보

평가 구간(2025년)의 실제 발전량·운영 데이터는 사용하지 않았고 보유하지도 않는다.
리더보드 점수를 이용한 역추론(예: 제출-피드백 반복으로 정답 탐색)도 하지 않았다.
후처리 파라미터는 학습 기간 홀드아웃에서만 결정한다.

**하한 후처리(`floor = 0.10 x 설비용량`)에 대한 소명**: 이 값은 대회 평가식이
"실제 발전량이 설비용량의 10% 이상인 시간대만 평가"한다고 **공개적으로 명시**한
데서 유도한 상수이며, 평가 데이터의 정답을 참조해 얻은 값이 아니다.
채점 대상 시간대는 정의상 실제값이 0.10cap 이상이므로 `max(예측, 0.10cap)`은
채점되는 어떤 시간대에서도 원 예측보다 오차를 키우지 않는다.

## 4. 외부 데이터 사용 규칙

**외부 데이터를 일절 사용하지 않는다.** 학습·추론에 쓰인 입력은 주최측이 제공한
`Data/` 이하 파일이 전부이다(LDAPS·GFS 예보, KPX 라벨, SCADA, info.xlsx,
sample_submission). 따라서 외부 데이터의 출처·수집시점·라이선스 소명 의무는
발생하지 않는다.

## 5. 사전 학습모델 사용 규칙

**사전 학습된 가중치를 일절 사용하지 않는다.** 모든 모델(LightGBM)은 본 저장소의
[src/train.py](../src/train.py)가 대회 제공 데이터만으로 처음부터 학습한다.

## 6. API 기반 모델 사용 제한

**외부 API 추론을 사용하지 않는다.** 학습·추론 전 과정이 참가자 로컬 PC에서
실행되며, 네트워크 접속 없이 재현 가능하다.

## 7. 기타 유의사항

| 항목 | 준수 내용 |
|---|---|
| 사용 언어 | Python 전용 |
| 인코딩 | 모든 소스·주석 UTF-8, 제출 CSV `utf-8-sig` |
| 학습/추론 분리 | [src/train.py](../src/train.py) / [src/inference.py](../src/inference.py) 별도 파일 |
| 제출 규격 | `forecast_id`·`forecast_kst_dtm` 원본 유지, 8,760행 x 5열 |
| 평가 데이터 용도 | 추론 입력으로만 사용(학습에 미사용) |
| 재현성 | 고정 시드(42/202/777), 결정론적 전처리 |

## 개발 환경

- OS: macOS (Darwin 25.5.0)
- Python 3.13.5 (Anaconda)
- 주요 라이브러리 버전은 [requirements.txt](../requirements.txt) 참고

## 재현 절차

```bash
pip install -r requirements.txt
python src/features_full.py   # 전처리 (전 변수 x 전 격자 피처 캐시)
python src/train.py           # 학습 + 홀드아웃 검증 + 모델 저장
python src/inference.py       # 추론 → submissions/submission.csv
```
